Technical Approach

How it works

1

Neural Network

MLP with Fourier features maps target pose (x, y, z, roll, pitch, yaw) to 6 joint angles. Trained on 50K samples.

~15mm initial error
2

Differentiable FK

Forward kinematics implemented in PyTorch using DH parameters. Enables gradient computation through the kinematic chain.

6 DH transforms
3

Test-Time Optimization

Gradient descent (Adam) minimizes position error. NN provides warm start, TTO refines to target precision.

100 optimization steps
✓

Sub-mm Result

Final joint configuration achieves industrial-grade positioning accuracy for the PUMA 560 workspace.

0.24mm mean error
